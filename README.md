# NeoLoop MVP
Исходный проект мобильной головоломки Flutter для Android.

## В этой заготовке
- Русский интерфейс, неоновое оформление.
- Игровая сетка и сенсорное управление.
- Простые цветные маршруты, перезапуск и подсказка.
- Сохранение уровня и настроек.
- Демонстрационная веб-панель рекламы в `admin-panel/`.
- GitHub Actions workflow для сборки APK.

## Запуск
Установите Flutter SDK и Android SDK, затем из корня проекта:
```bash
flutter pub get
flutter run
flutter build apk --release
```
APK после сборки: `build/app/outputs/flutter-apk/app-release.apk`.

## Реклама и администратор
Рекламная сеть не подключена. Рекомендуемый первый вариант — Google AdMob, если он доступен для аккаунта и региона. Используйте тестовые рекламные идентификаторы во время разработки, получите согласие пользователя там, где это требуется, и не показывайте рекламу поверх головоломки.
`admin-panel/` — локальный демонстрационный макет. Его настройки сохраняются только в браузере и НЕ управляют установленным приложением. Для production нужен backend, аутентификация и серверная роль единственного администратора. Демопароль в HTML нельзя использовать в интернете.
